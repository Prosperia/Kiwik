# About Kiwik

The script is an SQLar Archive browser that has been created for viewing offline archives of Dokuwiki instances.

Kiwik is a younger brother of [Kiwix](https://github.com/kiwix).

## How to use ?
1) Create an SQLite archive of files with the script provided in "_bin". directory.
2) If your system does not provide the "sqlar" install it from the "DEB" subdirectory ( only available for Debian packager, otherwise go to https://www.sqlite.org/cli.html#_sql_used_to_implement_sqlite_archive_operations_ ).
3) Put the database into the "db" subdirectory, included in the Apache web server local document tree.
4) Enjoy !
